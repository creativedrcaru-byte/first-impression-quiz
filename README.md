# 다음 중 악인을 고르세요.

강의용 첫인상 퀴즈입니다. 1번부터 8번까지 두 사람의 사진과 설명을 보고 A/B 중 하나를 선택합니다.

- 기본 방식: 선택하면 다음 문항으로 이동하고 마지막에 점수와 전체 정답 공개
- 선택 옵션: 매 문항 선택 후 정답 공개
- 이전 문항, 다시 시작, 전체 화면, A/B 키보드 선택 지원
- 서버에 응답이나 개인정보를 저장하지 않는 정적 웹사이트

사진·설명·정답은 강의자가 제공한 원본 이미지 기준입니다. 첫인상을 토론하기 위한 활동으로 성격이나 도덕성을 진단하는 검사가 아닙니다.
